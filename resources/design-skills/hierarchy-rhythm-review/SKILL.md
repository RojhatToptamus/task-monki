# Hierarchy and rhythm review

Hierarchy guides the eye.
Rhythm creates consistent repetition with useful variation.
Review both against the selected design system and product goal.

## Pass 1: Hierarchy

For each screen or major section, identify what a user sees first, second, and third.
Check these signals:

- size and scale
- color and contrast
- weight and emphasis
- position and reading order
- space around important content
- action priority

The main purpose and primary action must be clear quickly.
Do not make all actions equally loud.
Do not let secondary decoration dominate the product task.

## Pass 2: Rhythm

Identify the current spacing and type scales from the source.
Check that repeated components use consistent structure, alignment, and density.
Check that sections use a small set of deliberate separation patterns.
Check that colors have clear roles and do not drift into near-duplicates.

Look for accidental differences of a few pixels.
Also look for total uniformity that makes a long surface hard to scan.
Use one strategic change only when it strengthens the narrative or task.

## Apply judgment

Do not replace every value with a mechanical four-pixel or eight-pixel rule.
Preserve intentional optical adjustments and existing system values.
Fix random values, flat priority, reversed emphasis, weak alignment, and inconsistent repetition.

For a small refinement, review only the affected hierarchy and nearby rhythm.
For a broad build, review the whole requested surface.
Report any judgment call that still needs user direction.
