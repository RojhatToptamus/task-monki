# Generic design review

Find choices that look like unexamined template defaults.
Treat each pattern as evidence, not a universal ban.
Existing brand and design-system rules take priority.

## Establish the intended direction

Read the brief, current source, references, and any design-system findings.
State the subject, audience, desired tone, and signature idea.
Judge each choice against that direction.

## Review the common failure modes

### Content

Remove filler, repeated claims, empty sections, decorative metrics, and unsupported facts.
Use specific labels and copy from the brief or product context.
Keep honest placeholders when a real asset is unavailable.

### Composition

Find repeated card grids that flatten the hierarchy.
Find large empty areas that exist only to mimic a landing-page template.
Find decoration that competes with the primary task.
Replace them with a composition that supports the content.

### Color and effects

Prefer a flat or restrained surface when a gradient has no purpose.
Question bright multi-color gradients, glass effects, glowing edges, and excessive blur when the context does not support them.
Trace colors to the selected palette or current tokens.

### Type and shape

Use the project fonts when they exist.
When they do not, use an intentional local or browser-safe stack.
Question a familiar default only when it conflicts with the intended tone.
Check that radii, borders, and shadows form one system.

### Imagery and icons

Use licensed local photography, professional illustration, current icons, or honest placeholders.
Do not present weak decorative SVG scenes as final imagery.
Use emoji only when it has a product or brand role.

### House styles

Question any repeated house style that lacks a reason from the brief.
Examples include warm cream with a display serif and terracotta accents, or neon gradients with glass cards.
Keep the style when the audience, brand, or subject supports it.

## Fix the result

Fix confirmed generic choices in the same turn.
Preserve choices that are supported by the brand or brief.
Do not replace one template with another.
Keep one strong idea and remove details that weaken it.
